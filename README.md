# Mi Página Web

Página web personal hecha con HTML, CSS y JavaScript, sin frameworks. Es un proyecto para practicar diseño responsive y manipulación del DOM.

## Vista previa

![Captura de la web](img/captura.png)

Demo en línea: https://usuario.github.io/mi-pagina-web

## Características

- Diseño responsive (móvil, tablet y escritorio)
- Menú de navegación con scroll suave
- Modo claro y modo oscuro
- Sección de proyectos con tarjetas
- Formulario de contacto con validación en JavaScript

## Tecnologías

- HTML5
- CSS3 (Flexbox y Grid)
- JavaScript (vanilla)

## Instalación

```bash
git clone https://github.com/usuario/mi-pagina-web.git
cd mi-pagina-web
```

## Uso

No necesita instalar nada. Abre el archivo `index.html` en tu navegador.

Si usas VS Code, también puedes instalar la extensión **Live Server** y pulsar *Go Live* para verla con recarga automática.

## Estructura del proyecto

```
mi-pagina-web/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── img/
│   └── captura.png
└── README.md
```

## Despliegue

La web está publicada con GitHub Pages: en el repositorio ve a *Settings → Pages*, elige la rama `main` y la carpeta `/ (root)`, y guarda.
